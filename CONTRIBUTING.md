# Contributing to InsumerAPI's open-source repositories

Thank you for helping. These repositories hold InsumerAPI's SDKs, agent tools, verifier and examples. InsumerAPI itself, the hosted API at `api.insumermodel.com`, is a separate service and is not open source.

## Before you start

- **Bugs:** open an issue in the repository concerned. Say which version you used, what you sent, what came back, and what you expected.
- **Security issues:** do not open a public issue. Use the repository's private advisory form (Security tab, then "Report a vulnerability"), or email support@insumermodel.com. See [SECURITY.md](SECURITY.md).
- **Larger changes:** open an issue first so we can agree on the approach before you write the code.

## Pull requests

- Keep each pull request to one change, with a short description of what it does and why.
- Run the repository's tests before you open it, and add a test for a fix where you can.
- Keep request and response shapes in step with the [API specification](https://insumermodel.com/openapi.yaml). These packages follow the API; they do not define it.
- Write public text in plain English. Do not name the infrastructure providers behind the API.

## Licensing

Each repository states its license in its `LICENSE` file. By submitting a contribution you agree that it is licensed under that repository's license, and that you have the right to submit it.

## Questions

Ask in an issue, or write to support@insumermodel.com. Documentation lives at [insumermodel.com/developers](https://insumermodel.com/developers/).
